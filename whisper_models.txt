# Catálogo estático dos modelos dos MOTORES ALTERNATIVOS (família Whisper). O motor padrão (Ollama) usa audio_models.txt.
#
# Formato (uma linha por modelo):   motor | modelo | tamanho aproximado do download | observação
#
# Motores:
#   openai-whisper  — pacote `openai-whisper` (PyTorch). Modelos .pt baixados para ~/.cache/whisper.
#   faster-whisper  — pacote `faster-whisper` (CTranslate2; mais rápido e leve que o original). Modelos do Hugging Face.
#   whisper-cpp     — executável `whisper-cli` do whisper.cpp (C/C++; sem Python/PyTorch). Um só motor: usa a GPU NVIDIA (CUDA)
#                     quando houver e, senão, a CPU (os dois executáveis são baixados do release oficial conforme a máquina).
#                     Modelos GGML `ggml-<nome>.bin` do Hugging Face (ggerganov/whisper.cpp), baixados para a pasta de dados do app.
#                     Os nomes foram escritos de memória: se um download der 404, ajuste a linha. Sufixos q5_0/q5_1 = quantizado.
#   nemo-speech-cpp — NeMo-Speech.cpp (NVIDIA, C++/ggml; sem Python/PyTorch; CPU, CUDA e Vulkan). Modelos GGUF com tamanho e
#                     SHA-256 fixos em transcritor/engines.py (NEMO_MODELS); aqui só a lista da tela. O Transcribe-30B vem da conversão
#                     da AtomicChat (comunidade; não é da NVIDIA) e é baixado em par (decodificador + codificador de 1,67 GB).
#   nemotron-vllm   — o Transcribe-30B NVFP4 oficial por um servidor vLLM (GPU Blackwell); o app é só cliente.
#   whisperx        — pacote `whisperx`: faster-whisper + VAD + alinhamento forçado por palavra (wav2vec2) +
#                     DIARIZAÇÃO (quem fala; exige token do Hugging Face). Usa os mesmos modelos do faster-whisper.
#
# REGRA DE NOMES: sempre o nome completo e específico do modelo (ex.: large-v3), nunca apelidos ambíguos
# como `large` ou `turbo`. Os modelos só são baixados quando o usuário os seleciona para gerar uma legenda;
# na tela, "baixado" só aparece para quem já está no disco.
#
# A ORDEM é a prioridade (recomendados primeiro). Linhas com # são comentários.
# Parâmetros: tiny 39M · base 74M · small 244M · medium 769M · large 1,55B · turbo 809M (large-v3 podado, 4 decoders).
# Todos geram timestamps por trecho de fala; com o whisperx, também por palavra.
# Fora do catálogo de propósito: gerações anteriores (large-v1, large-v2) e modelos só para inglês (.en e distil-*); os do catálogo são
# todos multilíngues (PT-BR incluído).
#
# Última revisão: 2026-11-10
